# nchanigeo-website

Starter Astro project for Nchani Geo.

## What I added

- src/layouts/Base.astro — minimal base layout that imports global styles and displays the logo
- src/pages/index.astro — starter homepage demonstrating the logo and basic content
- src/styles/global.css — simple global stylesheet

The logo image is at: `public/images/logo.png` (already uploaded).

## Requirements

- Node 18+ (or a supported Node version for Astro 5)

## Install & run

```bash
npm install
npm run dev    # local dev server
npm run build  # production build
npm run preview # preview the production build locally
```
